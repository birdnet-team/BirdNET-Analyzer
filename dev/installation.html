Download & Setup

GUI installer

You can download the latest BirdNET-Analyzer installer for Windows and MacOS from our Releases page. This installer provides an easy setup process for running BirdNET-Analyzer on your system. Make sure to check to select the correct installer for your system.

Note

The macOS installer needs a Mac with Apple silicon (M1 or newer) and macOS 15 or later.

Windows Package Manager

On Windows, once the package is listed in the Windows Package Manager, you can also install and upgrade BirdNET-Analyzer with:

winget install BirdNETTeam.BirdNETAnalyzer
winget upgrade BirdNETTeam.BirdNETAnalyzer

Linux

Two packages are attached to each release. Both need an x86_64 distribution with glibc 2.35 or newer, such as Ubuntu 22.04, Debian 12 or Fedora 36 and later.

  • BirdNET-Analyzer-<version>-linux_x86_64.AppImage runs without installation: make the file executable and start it. The command line tool is included, ./BirdNET-Analyzer-<version>-linux_x86_64.AppImage analyze --help shows its options.

  • birdnet-analyzer_<version>_amd64.deb is for Debian, Ubuntu and their derivatives. It adds a menu entry and the birdnet-analyzer-gui and birdnet-analyze commands:

    sudo apt install ./birdnet-analyzer_<version>_amd64.deb

Settings and the downloaded models are kept in ~/.local/share/BirdNET-Analyzer-GUI.

Models and the first start

The macOS installer and the Linux packages contain the default BirdNET 3.0 model, including its species range model, so the first analysis works without an internet connection. Everything else is downloaded the first time it is used and kept for later runs, with the progress shown in the GUI: the other models (BirdNET 2.4, about 80 MB, and Perch, about 380 MB), and the model that training needs to export a custom classifier as a TFLite or Raven model (about 320 MB for BirdNET 3.0, about 125 MB for 2.4). The first training with one of these exports downloads it as soon as the training data are loaded. An analysis never does, and neither does a training that saves only the detached classifier. An installer without the default model downloads it the same way, about 380 MB, on the first analysis or training.

The installed application keeps its models in

  • %LOCALAPPDATA%\BirdNET-Analyzer-GUI\models on Windows,

  • ~/Library/Application Support/BirdNET-Analyzer-GUI/models on macOS,

  • ~/.local/share/BirdNET-Analyzer-GUI/models on Linux.

The settings tab of the GUI shows this directory and lets you choose another one, for example on a drive with more space; models that are already downloaded stay where they are and have to be moved by hand. Setting the environment variable BIRDNET_APP_DATA to a directory overrides both. A pip installation without either uses the directory of the birdnet library (%APPDATA%\birdnet, ~/Library/Application Support/birdnet or ~/.local/share/birdnet).

Computers without internet access. Models the installer does not contain have to come from a computer that is online and runs the same BirdNET-Analyzer version. There, run one analysis with each model you need. For training, also run one training with a TFLite or Raven export, on the BirdNET version (2.4 or 3.0) you will train on. Then copy the whole model directory, hidden files included, into the same place on the offline computer, or onto a drive and select that directory in the settings tab.

A pip installation can fetch the export model without a training run, in its own environment ('2.4' for BirdNET 2.4):

python -c "import birdnet_analyzer, birdnet; birdnet.load('acoustic', '3.0', 'pb')"

With BIRDNET_OFFLINE=1 set, nothing is downloaded and a missing model is reported at once. Training reports a missing export model once the training data are loaded, before the tuning and the training itself.

Restricted networks. The models come from zenodo.org, github.com (which redirects to githubusercontent.com) and tuc.cloud; a firewall has to allow these. The GUI and the command line tools verify downloads with the certificates of the operating system, so a company or campus proxy that inspects HTTPS works as long as its certificate is installed there, as it is for the browser. A proxy entered in the Windows settings is used, as are the environment variables HTTP_PROXY and HTTPS_PROXY; an automatic proxy configuration script is not.

Uninstalling BirdNET-Analyzer keeps the models and the settings. To remove them as well, delete the model directory and, on Windows, %APPDATA%\BirdNET-Analyzer-GUI.

Raven Pro

If you want to analyze audio files without any additional coding or package install, you can now use Raven Pro software to run BirdNET models. After download, BirdNET is available through the new “Learning detector” feature in Raven Pro.

For more information on how to use this feature, please visit the Raven Pro Knowledge Base.

Download the newest model version here, extract the zip-file and move the extracted folder to the Raven models folder. On Windows, the models folder is C:\Users\<Your user name>\Raven Pro 1.6\Models. Start Raven Pro and select BirdNET_GLOBAL_6K_V2.4_Model_Raven as learning detector.

Python Package

The easiest way to setup BirdNET on your machine is to install birdnetlib or birdnet through pip with:

pip install birdnetlib

or

pip install birdnet

Please take a look at the birdnetlib user guide on how to analyze audio with birdnetlib.

When using the birdnet-package, you can run BirdNET with:

import birdnet

if __name__ == "__main__":
    model = birdnet.load("acoustic", "3.0", "onnx")
    predictions = model.predict("soundscape.wav")

For more examples and documentation, make sure to visit pypi.org/project/birdnet/.

For any feature request or questions regarding birdnet, please add an issue or PR at github.com/birdnet-team/birdnet.

Command line installation

Requires Python 3.11 to 3.13.

Clone the repository

git clone https://github.com/birdnet-team/BirdNET-Analyzer.git
cd BirdNET-Analyzer

Install the packages

pip install .

Note

If you also want to use the GUI, you need to install the additional packages with: pip install .[gui]. Same goes for the training tools and the embedding/search tools: pip install .[train] and pip install .[embeddings].

Use pip install .[all] to install all packages.

On Linux, the gui extra installs PySide6 for the application window. Qt needs the system’s xcb libraries; on Debian and Ubuntu, sudo apt install libxcb-cursor0 libxcb-icccm4 libxcb-keysyms1 libxcb-shape0 libxkbcommon-x11-0 covers the ones a desktop installation may lack.

Verify the installation

python -m birdnet_analyzer.analyze <some-audio-file.wav>
