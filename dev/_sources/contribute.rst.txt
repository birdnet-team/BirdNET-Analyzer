How To Contribute
=================

Feel free to clone the `repository <https://github.com/birdnet-team/BirdNET-Analyzer>`_ and contribute to the project. We are always looking for new ideas and improvements. If you have any questions, please don't hesitate to ask.

Let us know if you have any ideas for new features or improvements or submit a pull request.

**Help us to improve the documentation!**

The documentation build imports BirdNET-Analyzer, so install your checkout with the ``docs`` extra, which adds Sphinx and its plugins, and build from the top folder of the repository:

.. code-block:: bash

   pip install -e ".[docs]"
   sphinx-build docs docs/_build

Open ``docs/_build/index.html`` with a browser of your choice.

Make your changes to the ``.rst`` files in the ``docs`` directory and submit a pull request.
